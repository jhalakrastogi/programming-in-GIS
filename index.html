Practical Learning in Class

Key GIS Programming Workflows Mastered in VS Code

Module 01

Adding & Loading Shapefiles

Learned how to programmatically set workspace directories, read vector shapefiles using Python scripts in Visual Studio Code, and verify feature layer attributes without opening desktop GUI menus.

Module 02

Automated Buffer Analysis

Wrote Python scripts to execute multi-distance spatial buffers around vector point, line, and polygon features. Learned how specifying exact linear units programmatically ensures consistent spatial proximity analysis.

Module 03

Feature Clipping Operations

Implemented automated clipping tools via code to extract sub-regions of spatial layers using study area boundaries. Mastered defining input layers, clip features, and output destination paths.

Module 04

Programmatic Map Layouts

Generated automated map layouts through script execution, including setting up map frames, applying symbology, adding scale bars, north arrows, titles, and exporting final maps to image formats.

Subject Reflection

Programming for GIS I — Personal & Practical Reflections

Practical & Personal Learning Reflection

Subject: Programming for GIS I | Semester: M.Sc. Semester I | IDE: Visual Studio Code

Before studying Programming for GIS I, my primary experience with geospatial software was limited to clicking through user interfaces in desktop GIS programs like ArcGIS Pro and QGIS. Transitioning into Visual Studio Code to handle spatial workflows programmatically shifted my understanding of GIS from manual mapping to reproducible computational processing.

In our practical sessions, we focused on fundamental vector manipulation tasks: programmatically loading shapefiles, performing buffer analysis around spatial features, clipping datasets to exact boundary extents, and generating map layouts through code. Writing scripts for buffering and clipping demonstrated how automated scripts eliminate repetitive manual steps, allowing entire workflows to execute consistently within seconds.

My main learning difficulty initially involved handling relative versus absolute file paths and managing output file overwrite settings. Resolving path errors taught me to inspect terminal execution logs carefully before rewriting entire scripts. Furthermore, I realized that a script executing without errors does not automatically guarantee accurate cartographic output; inspecting spatial reference systems and feature geometry counts remains essential.

This practical foundation in VS Code provides a solid base for scaling up to complex geospatial scripts, batch processing, and automated spatial analytics in future research and professional projects.
